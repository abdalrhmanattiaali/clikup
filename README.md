# 🚀 نظام إشعارات ClickUp المحسّن مع AI

نظام متقدم لإدارة المهام وإرسال إشعارات ذكية عبر WhatsApp مع نظام تحفيزي مدعوم بالذكاء الاصطناعي من Claude.

## ✨ الميزات الرئيسية

### 1. 📢 نظام إشعارات محسّن

#### إشعارات اكتمال المهام المطورة
- ✅ عرض اسم المهمة المكتملة بشكل واضح
- 👤 عرض اسم الشخص الذي أنجز المهمة
- 🔗 إذا كانت المهمة فرعية، يتم عرض المهمة الرئيسية مع رابط مباشر لها
- 📊 تجميع المهام حسب المشاريع الرئيسية لسهولة القراءة

**مثال على الإشعار:**
```
🏆 محمد أنجز 3 مهام:

  تابعة للمهمة: تطوير موقع الشركة 🔗 https://tinyurl.com/xxx
    ◦ تصميم واجهة المستخدم ✓ بواسطة: محمد 🔗 https://tinyurl.com/yyy
    ◦ برمجة صفحة الرئيسية ✓ بواسطة: محمد 🔗 https://tinyurl.com/zzz

- كتابة المحتوى التسويقي ✓ بواسطة: محمد 🔗 https://tinyurl.com/www
```

### 2. 📊 نظام تحليل الإنتاجية

#### تحليل ذكي للأنماط الإنتاجية
- 📈 حفظ بيانات المهام المنجزة في ملف JSON
- 📅 تحليل الإنتاجية حسب أيام الأسبوع
- 🏆 تحديد اليوم الأكثر إنتاجية لكل عضو
- 📊 إحصائيات شاملة لآخر 7 أيام (قابلة للتخصيص)
- 🔍 تتبع آخر 10 مهام منجزة

**البيانات المحفوظة:**
```json
{
  "type": "task_completed",
  "taskId": "abc123",
  "taskName": "تصميم الواجهة",
  "userId": "محمد",
  "timestamp": 1699420800000,
  "isSubtask": true,
  "parentId": "parent123"
}
```

#### Endpoint للاختبار:
```
GET /test-analytics/:userName?
```

### 3. 🤖 نظام تحفيزي ذكي بواسطة Claude API

#### استبدال OpenAI بـ Claude
تم استبدال OpenAI GPT بـ **Claude 3.5 Sonnet** من Anthropic للحصول على:
- 💬 رسائل تحفيزية أكثر إنسانية وشخصية
- 🧠 تحليل أعمق للأنماط السلوكية
- 🎯 رسائل مخصصة بناءً على الإنتاجية
- 🌟 أسلوب عربي فصيح وجميل

#### المميزات التحفيزية الجديدة

**1. رسائل صباحية ذكية (`sendAIMorning`)**
- تحلل مهام اليوم المفتوحة
- تدرس إنتاجية آخر 7 أيام
- تحدد اليوم الأكثر إنتاجية
- ترسل رسالة تحفيزية مخصصة

**2. تقارير نهاية اليوم (`sendAIDaily`)**
- تحليل الإنجازات اليومية
- مقارنة مع الأيام السابقة
- رسائل تشجيعية مبنية على الأداء
- اقتراحات للتحسين

**3. ملخص الفريق (`sendAIGroupHighlights`)**
- تحليل أداء الفريق بالكامل
- تحديد أفضل المؤدين
- رسائل جماعية محفزة
- مقارنات صحية بين الأعضاء

**4. رسالة مساء الخير (`sendAIGroupGoodnight`)**
- احتفال بإنجازات اليوم
- رسائل دافئة وإنسانية
- إيقاف الإشعارات لمدة 10 دقائق للراحة

**5. نظرة أسبوعية (`sendAIWeekly`)**
- تحليل المهام القادمة
- دراسة الأنماط الأسبوعية
- رسائل تخطيط وتحضير

#### مثال على التحليل الذكي:
```javascript
{
  totalCompleted: 15,
  dayStats: {
    'الأحد': { count: 3, tasks: [...] },
    'الإثنين': { count: 5, tasks: [...] },
    'الثلاثاء': { count: 2, tasks: [...] },
    // ...
  },
  mostProductiveDay: 'الإثنين',
  mostProductiveDayCount: 5,
  recentTasks: [...]
}
```

**رسالة AI مخصصة:**
```
🌅 صباح النشاط

مرحباً محمد! 👋

لاحظت أن يوم الإثنين هو الأكثر إنتاجية بالنسبة لك (5 مهام)!
اليوم لديك 3 مهام مستحقة - أنت قادر على إنجازها كما فعلت الأسبوع الماضي.

تذكر: الإنجازات الصغيرة تصنع النجاحات الكبيرة 💪
```

### 4. 🎨 محتوى إلهامي ذكي

#### نظام محتوى إلهامي متقدم
- 🌤️ يتكيف مع الطقس الحالي في القاهرة
- ⏰ يراعي الوقت من اليوم (صباح/ظهيرة/مساء)
- 🍂 يتناسب مع الفصل الحالي
- 🔄 يتجنب التكرار عبر تتبع الرسائل السابقة
- 📚 يحفظ سجل آخر 10 رسائل لتجنب التكرار

**مثال:**
```
💡 رسالة اليوم

في هدوء المساء وبرودة الشتاء، تذكّر أن أعظم الإنجازات
تُصنع في لحظات الصبر والتأمل. استثمر هذا الوقت في
التخطيط لغدٍ أفضل 🌙✨
```
