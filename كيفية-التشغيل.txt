📍 موقع الملف: /home/user/clikup/.env

🔧 ماذا تفعل الآن؟

1. افتح ملف .env:

   nano .env

   أو أي محرر نصوص آخر

2. غيّر السطر 5 وضع مفتاح Anthropic الحقيقي:

   ANTHROPIC_API_KEY=sk-ant-api03-your-key-here
                     ↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑
                     ضع مفتاحك الحقيقي هنا

3. احصل على المفتاح من:
   https://console.anthropic.com/

───────────────────────────────────────────────────────────────

📦 ثبّت المكتبات:

cd /home/user/clikup
npm install

───────────────────────────────────────────────────────────────

🚀 شغّل النظام:

npm start

أو:

node index.js

───────────────────────────────────────────────────────────────

✅ المميزات الآن:

• ✅ جميع المفاتيح في ملف .env آمن
• ✅ لا حاجة لتعديل الكود يدوياً
• ✅ يمكن تغيير الإعدادات بسهولة
• ✅ ملف .env محمي ولن يُرفع لـ Git

───────────────────────────────────────────────────────────────

🔑 الإعدادات المتاحة في .env:

ANTHROPIC_API_KEY      → مفتاح Claude AI (مطلوب!)
CLICKUP_TOKEN          → توكن ClickUp (موجود)
CLICKUP_TEAM_ID        → معرف الفريق (موجود)
CLICKUP_LIST_ID        → معرف القائمة (موجود)
PORT                   → رقم البورت (5014)
WHATSAPP_GROUP_NAME    → اسم مجموعة الواتساب

───────────────────────────────────────────────────────────────

📖 مراجع مفيدة:

• INSTALL.md           → دليل التثبيت الكامل
• دليل-التشغيل.md      → شرح تفصيلي
• ابدأ-من-هنا.txt      → البداية السريعة

───────────────────────────────────────────────────────────────

⚠️ مهم جداً:

• لا تشارك ملف .env مع أحد (يحتوي على مفاتيح سرية)
• لا ترفع .env إلى GitHub (محمي تلقائياً بـ .gitignore)
• احتفظ بنسخة احتياطية من .env في مكان آمن
